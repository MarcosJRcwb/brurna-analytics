# BRURNA Analytics - Processador de Logs TSE

Sistema para download, parsing e análise de logs das urnas eletrônicas do TSE.

## 🚀 Começando

### 1. Instalação
```bash
# Clone o projeto
cd C:\Users\marco\OneDrive\Projetos\

# Crie ambiente virtual
python -m venv .venv

# Ative no Windows
.venv\Scripts\activate

# Instale dependências
pip install -r requirements.txt

# Ou execute o script de setup
python init_project.py
